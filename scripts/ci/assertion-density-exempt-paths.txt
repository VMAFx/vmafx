# Exact-path exemption list for scripts/ci/assertion-density.sh (issue #3347).
#
# The gate scans every non-mirror C source by default; the files below are the
# code the fork inherited (upstream Netflix and its NVIDIA co-authored CUDA
# files) and vendored third-party sources (Xiph, Daala, the IQA library, cJSON,
# libsvm, dav1d). They are exempt because the fork does not own them and cannot
# absorb fork-local asserts without breaking the sync with their source of
# truth; new fork code carries an assert per non-trivial function instead.
#
# Keep sorted (load_manifest() in scripts/ci/pelorus_mirror.py refuses an
# unsorted or duplicated list; entries are validated as exact repository
# paths). The gate fails when a listed path no longer exists, so entries are
# pruned in the same change that removes their file.
