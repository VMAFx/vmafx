## Gitea artifact writer uses ruamel.yaml round-trip mode (2026-11-18)

`fix/issue-3052-ruamel-yaml`, [issue #3052](https://github.com/VMAFx/vmafx/issues/3052). `scripts/ci/check_gitea_artifact_steps.py` now edits workflows with `ruamel.yaml` 0.19.1's round-trip mode instead of regex-and-indent reconstruction, and the pre-commit and tooling-test locks record the dependency. A rebase must keep the `_yaml(round_trip=True)` settings (`preserve_quotes`, `width = 1000`, `explicit_start`, `indent(mapping=2, sequence=4, offset=2)`), the `name`/`if`/`uses`/`with` twin order, `_twin_step`, `_ensure_guard_and_twin`, the unchanged-round-trip refusal, and the byte-stability / YAML 1.2 / flow-mapping tests; upstream's PyYAML version has neither the dependency nor the same lock inputs.
