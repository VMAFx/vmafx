| [ADR-1234](1234-local-preflight-gate.md) | Add `make preflight` (`scripts/dev/preflight.sh`), a local gate that builds with every compiler CI does — gcc, clang, 32-bit, ASan/UBSan — plus clang-tidy, cppcheck and a static check for constructs MSVC rejects. The documented local gate used ONE compiler, so a change could be green locally and red in several CI lanes at once: on 2026-09-07 one branch shipped a 32-bit-false `static_assert`, an MSVC-invalid `align((N))`, and a clang-invalid `__attribute__(x)` in a single afternoon, costing three round-trips and about three hours of merge-window time on a queue that allows one active PR. Each is caught locally in seconds; the script was validated by planting all three breaks. It deliberately considers uncommitted work and skips (not fails) stages whose toolchain is absent. | Accepted | ci, build, agents, fork-local |
