| [ADR-0528](0528-cli-parse-test-stderr-pipe-drain-and-error-fallback.md) | `test_cli_parse_long_only_args::test_threads_invalid_optarg_does_not_assert` regression close (2026-05-18): the test fork-harness allocated a 4 KiB stderr buffer and stopped reading once full, so once `usage()`'s help text grew past 4 KiB the child either SIGPIPE'd (signal 13) or SIGABRT'd (signal 6 via aborting stdio) — the test's `WIFEXITED` check rejected the run.
