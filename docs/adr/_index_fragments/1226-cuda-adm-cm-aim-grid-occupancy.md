| [ADR-1226](1226-cuda-adm-cm-aim-grid-occupancy.md) | Pick the CUDA AIM CM kernel's `rows_per_thread` from the device SM count (4, or 2 on frames too small to fill half the SMs) instead of a fixed 8, and deliberately omit `__launch_bounds__`. Measured: the kernel is grid-limited, not occupancy-limited — at `rows=8` a 1080p frame launches 42 blocks against an RTX 4090's 128 SMs, and `__launch_bounds__(128, 5)` cutting registers 255 → 96 changed runtime by 0.6%. The `rows_per_thread` fix takes the whole ADM CUDA feature 19% (1080p) to 31% (576x324) faster with bit-identical output. | Accepted | cuda, performance, adm, fork-local |
