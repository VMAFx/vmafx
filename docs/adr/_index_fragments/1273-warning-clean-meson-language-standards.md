| [ADR-1273](1273-warning-clean-meson-language-standards.md) | Language standards use Meson's ordered built-in preferences (`c23,c2x,c17` and `c++23,c++latest`) instead of direct `-std`/`/std` project arguments. The selected option now reaches both compiler probes and targets without Meson's manual-standard warning; an explicit `std::expected` probe still rejects a C++ library that accepts the spelling but lacks the required API. GCC 13 uses the pre-ratification C23 spelling and MSVC uses its newest Meson-supported ISO C mode (C17) plus C++ latest. Supersedes ADR-1056 and amends ADR-0692's all-toolchains C23 claim. | Proposed | build, meson, c23, cpp23, windows, warnings, fork-local |
