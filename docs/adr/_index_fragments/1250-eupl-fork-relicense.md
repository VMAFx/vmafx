| [ADR-1250](1250-eupl-fork-relicense.md) | Licence fork-authored code under EUPL-1.2 and leave every Netflix-derived and third-party file on the terms it already carries. 946 files declared `SPDX-License-Identifier: BSD-3-Clause-Plus-Patent`, which is not a real SPDX identifier, while fork code otherwise spread across five different licences plus 223 prose-only grants and 147 files with no notice at all. A file moves only if it passes three mechanical vetoes — no counterpart path upstream (accounting for the ADR-0700 `libvmaf/` → `core/` remap and excluding `compat/python-vmaf/` as Netflix's relocated tree), no matching filename upstream, and no copyright line other than Lusoris — which moved 1,622 files and deliberately left 630 alone. The 123 dual `... OR MIT` Go files become plain EUPL-1.2, since an MIT option would defeat the reciprocity. Because `libvmaf.so` links fork and Netflix code together, the shipped library is effectively copyleft from here on: a breaking change for permissive consumers, who can use Netflix upstream instead. | Proposed | license, compliance, process, docs, breaking-change |
