| [ADR-1232](1232-oneapi-2026-apt-on-debian.md) | Install oneAPI 2026.1.1 from Intel's apt repo onto Debian 13 for both compiler and runtime, instead of pulling Intel's container images. `intel/oneapi-basekit` is a retired repo (last tag 2025.3.2) — Intel continued under `intel/oneapi` — and the apt kit meta-packages were retired too, so `dev/Containerfile`'s unversioned `intel-basekit` had silently frozen the dev container on 2025.3.2 with no error. Crossing to 2026 is a restructure, not a pin bump: the SYCL soname moved (`libsycl.so.8` → `.so.9`, a hard ABI break that overrides runtime ≥ compiler), `intel/oneapi-runtime` stops at 2026.0.0 so the image route would put the runtime behind the compiler, and Intel's Ubuntu-only images carry glibc 2.43 against Debian 13's 2.41. The runtime image installs the Intel NEO driver explicitly because Intel's image bundles it and Debian does not package it — without it SYCL loads and every device query fails silently. Published tag becomes `-oneapi2026`. | Accepted | build, sycl, ci, security, fork-local |
