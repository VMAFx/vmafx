Enforcement moves from ADR-0141's touched-files rule to a whole-tree **ratchet**: `scripts/ci/tidy-ratchet.py` measures every TU of a compile database (diagnostics deduplicated by path/line/column/check, plus NOLINTs without an inline ADR citation) and compares per file against the committed `scripts/ci/tidy-baseline-<lane>.json`; a file above its baseline fails, a cleaned file must tighten the baseline in the same PR, an uncompilable TU fails closed. The `cpu` lane is the aggregator-required context `Clang-Tidy Ratchet (Whole Tree)` and replaces the nightly swallowed scan; `cuda`/`sycl`/`hip` baselines (from the 2026-09-02 workstation measurement) run nightly and via `make tidy-ratchet LANE=…` until hosted toolchains exist.
