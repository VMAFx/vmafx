| [ADR-1233](1233-github-native-release-notes.md) | Let GitHub compose the release body from merged PRs (`changelog-notes-type: "github"` + `.github/release.yml`) instead of release-please's commit-subject list, and archive oversized CHANGELOG bodies. GitHub groups release notes BY LABEL and this repo labelled almost nothing — 32 of the last 40 merged PRs had no label — so `.github/workflows/pr-type-label.yml` derives a `type:*` label from the Conventional-Commit prefix the commit-msg hook already mandates, and the 160 already-merged PRs were backfilled. `rollover-changelog-fragments.sh --archive-over N` (default 400) moves an oversized rendered body to `docs/changelog-archive/X.Y.Z.md` and leaves a per-section index: for 1.0.0 that is a 15-line index over 2,345 entries instead of a 27,502-line section. | Accepted | ci, docs, build, fork-local |
