- **Install a CMake package for libvmafx.** `<libdir>/cmake/vmafx/vmafxConfig.cmake` and `vmafxConfigVersion.cmake` give CMake projects the `vmafx::vmafx` imported target through `find_package(vmafx)`. The new `cmake_package` Meson option (default `auto`) skips the files with a warning when the `cmake` binary is missing, and `enabled` makes a missing `cmake` fail configure (#2437).
