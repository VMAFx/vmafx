- **Pre-push check for exit-code-only tests under `scripts/ci/tests/`.** The `check-exit-code-only-tests` pre-push hook runs `scripts/ci/check_exit_code_only_tests.py --changed-against origin/master` over `scripts/ci/tests/test_*.py` and refuses added or modified `def test_*` functions that run a process or checker and compare only its return code with the literal `0` (`# exit-code-only: <reason>` with a reason of at least 10 characters excuses justified cases). During a push it checks the outgoing commit named by `PRE_COMMIT_TO_REF`, not the working tree. See [Test suites and the checks that run them](docs/development/test-suites.md#exit-code-only-test-check-scriptscitests).
