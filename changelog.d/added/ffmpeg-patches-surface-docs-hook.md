- **Local check for retired FFmpeg filter names.** A commit or push that touches documentation, the FFmpeg patch series, its tests or a fork build config now runs `scripts/ci/ffmpeg-patches-surface-check.sh --surface-only` (hook `ffmpeg-patches-surface-docs`), so a retired filter or option named outside the migration guide fails locally instead of first in CI. The new `--surface-only` mode runs only the tree checks and needs no PR body or `origin/master`.
