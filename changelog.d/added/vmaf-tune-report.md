- `vmaf-tune report` — new subcommand renders an HTML or Markdown profile card from the JSON dumps of `compare`, `ladder`, and `tune-per-shot`. Self-contained output (inline SVG charts in HTML, inline base64 PNGs or sidecar files in Markdown), shows source metadata via `ffprobe`, rate-distortion plot, picked ABR rungs, per-shot timeline, and codec ranking. Lives at `tools/vmaf-tune/src/vmaftune/report.py` + `vmaf-tune report` CLI entry. `--format html|markdown|both`. 5 unit tests in `tools/vmaf-tune/tests/test_report.py`.
