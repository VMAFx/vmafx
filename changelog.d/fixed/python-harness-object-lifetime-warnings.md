- Fixed two object-lifetime defects in the classic Python harness that the ADR-1278 warnings-are-errors policy turns into test failures on Python 3.14. `command_line_test.VmafexecCommandLineTest` and `ssimulacra2_test.Ssimulacra2SnapshotTest` allocated their output path with `tempfile.NamedTemporaryFile().name`, which drops the only reference to a wrapper whose finaliser raises `ResourceWarning` whenever the cyclic GC later reaches it — surfacing in whichever test happened to be running at that moment; both now use `tempfile.mkstemp()` and close the descriptor immediately, so the path carries no finaliser. `routine.generate_dataset_from_raw()` reached `sureal`'s `SubjectiveModel.from_dataset_file()`, which imports the dataset file with `importlib.machinery.SourceFileLoader.load_module()` — deprecated since Python 3.4 and scheduled for removal in 3.15; the import now goes through the harness's own `importlib.util`-based `tools.misc.import_python_file()` and the already-parsed dataset is handed to the sureal dataset reader, which is what `from_dataset_file()` does after its import.
