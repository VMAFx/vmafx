- **Keep credentials under any name out of Meson test logs.** `scripts/ci/run_meson_test.py` now also removes environment names that look like credentials (`*TOKEN*`, `*SECRET*`, `*API_KEY*`, `*_PAT` and similar) before Meson writes `testlog.txt` and `testlog.json`, and the new `testlog-credential-scan` pre-commit hook refuses a commit while a `meson-logs` file in the checkout holds a credential-shaped value, for example after a direct Meson run (ADR-3400).
