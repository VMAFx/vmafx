## 1.0.0-rc.1 (2026-09-19)


###   BREAKING CHANGES

* **license:** fork-authored code is EUPL-1.2; see ADR-1250 and the licence section of README.md.
* **deps:** import paths for golusoris config/clock/clikit moved under core/.
* **cuda:** the CUDA backend no longer supports Turing (sm_75) or older.
* **feature:** finalize the ansnr feature extractor removal (ADR-0865) ([#1295](https://github.com/VMAFx/vmafx/issues/1295))
* **model:** every score produced without an explicit --model changes. On the standard 576x324 pair the pooled VMAF moves from 76.667831 to 82.816059. Pin `--model version=vmaf_v0.6.1` to keep the old numbers. No API, flag or output schema changed, and no model was removed.
