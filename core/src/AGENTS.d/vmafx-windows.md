# VMAFx window scores (ADR-2074)

- Files: `window.c` (windows, set, completion thread, callback thread, hooks, engine lock, `vmafx_context_max_in_flight`), `window_clock.c` (`VmafxWindowClock`, #2138 `n_stats` rule), `score.c` (`vmafx_pool_engine()`, `vmafx_pool_target_name()`: the ONE pooling of sync calls + windows, HISS-19). Never a second pooling path.
- Completion thread per context (maintainer 2026-10-06, "Dedicated completion thread"): started by first window; sleeps on `set->wake` (cond var, no polling); woken by `wake_locked()` = `generation++` under set lock. Wakers: worker jobs via engine frame listener (`vmaf_engine_set_frame_listener()` in `vmafx_context_create()`, called at end of `threaded_extract_batch_func()`), `vmafx_windows_note_index()` (end of `vmafx_submit()` + `vmafx_context_import_score()`), `vmafx_windows_note_flush()`, `vmafx_window_submit()`. Pass = `evaluate()`; `seen` = generation of last pass.
- Engine lock: `vmafx_engine_enter(context)` locks `set->engine_lock`, `vmafx_engine_leave(context, previous)` unlocks. Every API engine call + completion thread probes / pooling go through it. Never nest enter. Order: engine lock BEFORE set lock, never reverse; set lock never held across engine call or callback. Without the lock: double model prediction (`-EINVAL` "cannot be overwritten") + TSan races (`test_engine_shared_with_the_completion_thread`).
- Set created with context (`vmafx_windows_init()` before first enter), never NULL after create; stream state (`have_scored`, `scored_last`, `flushed`) lives in set under set lock, snapshot per pass (`WindowStream`).
- Probes never fence: `vmaf_engine_feature_written()`, `vmaf_engine_try_score_at_index()` (= `engine_score_at_index(fence=false)`, needs `vmaf_predict_inputs_written()` first), `vmaf_engine_try_score_at_index_model_collection()`. `fence_for_read()` waits whole thread pool; never call sync score fns from window code. -EAGAIN / -EINVAL = not final before flush, `VMAFX_E_NOTFOUND` after.
- Cursor per window (completion thread only): `[first, cursor)` final (scores write-once, ADR-0154). Skip `i % n_subsample` frames; `n_scored` = multiples in range.
- Model probe writes model score (same predict as first sync read, under engine lock). Model-set probe needs #2206 (`read_predicted_collection_score()`).
- Publish: result written once, then `vmafx_host_fence_signal(done)`; poll / wait lock-free, any thread incl. feeder.
- Callback thread separate from completion thread (blocking callback must not stop completion; `test_release_of_a_queued_window`): `set->callback` cond, drains queue at stop. TLS `vmafx_delivering_set` on callback thread (`_Thread_local`, `__declspec(thread)` for MSVC C). Release waits for running callback unless TLS says self.
- Destroy: `vmafx_windows_pause()` before engine close: `next_work()` evaluates pending generations BEFORE ack (final windows complete with values, `test_destroy_with_a_pending_wake`); close fails -> `vmafx_windows_resume()` (`test_failed_destroy_keeps_windows`); else `vmafx_windows_close()`: fail open (`VMAFX_E_INVALID`), publish, stop, join completion then callback thread, drop set. Never free under set lock: window's last ref drops set ref.
- Open windows capped 1024 -> `VMAFX_E_BUSY` naming `context` (check + push in one locked section).
- In-flight bound = engine `thread_pool.c` queue (no VMAFx queue): `vmaf_engine_max_in_flight()` = `R + 2*T*(R+1)` + 1 device. Change of `batch_job_take_pictures()`, enqueue capacity or GPU double buffer -> recompute + `test_vmafx_window_live` unpaced case.
- motion2 / motion3 of frame i final once SADs of frames 0..max(i + 1, min_idx) in (ADR-2090). Engine derives them in `advance_extractors()`: end of `vmaf_engine_read_pictures()` (before `vmafx_submit()` wakes), `fence_for_read()`, and `vmaf_engine_advance()`, which `evaluate()` calls under the engine lock before probing (`advance_engine()`), so a SAD a worker appends (frame listener wake) completes a VMAF window while the feeder stalls. Windows over them / any VMAF model complete one frame after `last` (device: one submit later, `motion_cuda` per 8-frame batch); last frame at flush. Window code has no motion case; never add one (`test_vmaf_window_completes_after_the_frame_after_last`, `test_vmaf_window_completes_while_the_feeder_stalls`).
- Clock: time windows in integer ns (`nearbyint(n_stats * 1e9)`, >= 1, <= 9.2e9 s), from first frame's pts; frame windows from first index; close on first frame past window; skip empty; finish partial unless full frame window; refused frame leaves clock unchanged.
- Tests: `test_vmafx_window` (public; sync == async every pool, flush partial, subsample, motion, model + set, 1024 open, callbacks, destroy, refusals; waits via `vw_complete()`), `test_vmafx_window_clock`, `test_vmafx_window_live` (Linux, static lib; cases: 60 fps texture import; poller thread; latency <= 2 periods unless sanitizer build; backpressure; host copies 0; release races; queued release; stalled feeder; destroy with pending wake; engine shared with completion thread), `test_vmafx_window_cli.py` (harness windows == CLI per-frame scores), `test_vmafx_lifetime` (`test_failed_destroy_keeps_windows`). Live tests `is_parallel: false`. TSan: `-Db_sanitize=thread`, repeat runs.
